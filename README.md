## 🚀 Running Locally

```bash
# 1. Unzip and navigate to the project directory
cd rishita-portfolio

# 2. Install dependencies
npm install

# 3. Start the Vite development server
npm run dev

# 4. Open in browser:
# http://localhost:5173/

# 5. Production build
npm run build
```
